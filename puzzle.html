8-Puzzle Lab

A sliding puzzle you can play yourself or hand to an A* solver — with two heuristics racing on the same board and a dashboard that benchmarks how they compare.

Overview

The problem

Search algorithms are usually compared as numbers in a terminal. That tells you which won, but not what either one was doing.

My approach

A five-screen Pygame app where the same board can be played by hand or solved by A*, and where two heuristics run side by side in real time.

Result

A resizable app that makes the difference between Manhattan Distance and Linear Conflict visible instead of theoretical.

Demo

What's in it

  • Solo play — solve it yourself, with an A* hint available whenever you're stuck
  • AI race — Manhattan Distance against Linear Conflict on an identical board, side by side
  • Statistics dashboard — benchmark across multiple puzzles and read the results as charts
  • Colour themes — selectable from a settings screen
  • Resizable window — the layout scales to any window size, with fullscreen on F11

Build notes

  • Racing without freezing the window

    A solver running to completion blocks the frame loop, so the search had to be stepped through in a way that keeps both boards animating and the interface responsive.

  • A fair comparison

    Both heuristics start from the same scrambled board and are measured the same way, so the race reflects the heuristic rather than luck.

  • Layout in a framework with no layout system

    Pygame draws pixels, not components — every screen had to scale proportionally rather than sit at fixed coordinates.
